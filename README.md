# 我的课表 · 面向高校学生的单页面课表工具

一个只用 HTML + CSS + 原生 JavaScript 写的课表工具，**单文件、零依赖、双击就能用**，也可以直接访问线上版本：

**https://rayn-star.github.io/timetable/**

## 它解决什么

高校课表有两个特点：**每周不一样**（单双周、调课、补课），**地点会变**（同一门课换教室）。大多数课表 App 只能存一份"标准周"，遇到调课就得自己记在本子上。

这个工具的做法是：把教务系统导出的 Excel 直接导入，按"周次"渲染——打开就是**这一周真实要上的课**。

## 功能

- **导入课表**：直接选择教务系统导出的 `.xlsx`，自动识别表头（课程名 / 上课周次 / 上课星期 / 开始节次 / 结束节次 / 教室名称），解析 `5-14周`、`6-18周(双)`、`3周,6-17周` 这类周次写法，展开成逐周数据。
- **按周显示**：顶部 `‹ 第 N 周 ›` 可以翻 1–18 周。停课、补课、单双周、临时换教室都会自动体现，不需要手工维护。
- **颜色随时段变浅**：早课（1–4 节）深绿、下午（5–8 节）中绿、晚上（9–10 节）浅色，一眼看出一天里的疏密。
- **点格子改课**：点空白格新增课程（星期和节次已预填），点已有课程可以修改或删除。
- **拖动换位**：按住课卡拖到另一个格子松手即可——主要用于应对临时调整。拖到已有课程的格子会先问一句，确认后替换。
- **换教学楼提示**：同一门课和上一节相比**换了楼**（`N8623` → `N3212`，或换到机房、操场）时，卡片左侧加深、地点前加 `↦`。同楼内换教室不标，避免满屏都是箭头。
- **待办清单**：表格形式，按课程分组；同一门课里内容相同的待办自动合并成一行（`×2`），勾选一次全勾。每节课后面有「记作业」按钮，随时把作业记进待办。

## 为什么"下课自动弹窗"没做

纯本地页面做不可靠：页面关掉就不会弹，标签页在后台时浏览器会节流定时器，手机锁屏更不会弹。

所以改成了**打开页面随时补记**：顶部「今天」条列出当天的课，每节课后面跟一个「记作业」按钮。效果接近，但不会漏、也不会骗你。

## 数据放在哪

全部存在**浏览器的 localStorage**，不上传任何服务器。

- 换浏览器、换设备、清浏览数据 → 课表要重新导入
- 所以提供了「导出 / 导入」JSON 备份

## 目录

```
index.html    # 全部代码（HTML + CSS + JS，单文件）
README.md
```

`index.html` 里有两块由脚本生成的区域，用注释标出边界，不建议手改：

- `@TERM_DATA_START / END`：逐周课表数据
- `@TERM_META_START / END`：数据来源与生成时间

## 已知限制

- **手机端不能拖拽**：用的是浏览器原生 HTML5 拖拽，触屏不认。要支持得改成"长按进入移动模式"。
- **只吃 .xlsx**：旧版 `.xls` 是二进制格式，页面内解析成本过高，请先另存为 `.xlsx`。
- **数据是"某一份导出"的快照**：教务改课之后，需要重新导出、重新导入。
